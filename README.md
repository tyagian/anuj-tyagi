# Anuj Tyagi — Portfolio Website

Personal portfolio site for [Anuj Tyagi](https://github.com/tyagian), Senior Site Reliability Engineer specializing in Cloud & AI Infrastructure.

## Pages

- **Home** — About, skills, leadership, education, highlights
- **Projects** — Open-source & innovation (Terraform provider, SentinelGuard, CNCF, Apache)
- **Publications** — Research, books, and technical articles
- **Speaking** — Conferences and workshops
- **Contact** — Email and social links

## Local preview

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Deploy

GitHub Pages workflow is configured in `.github/workflows/pages.yml`. Enable Pages in the repository settings (Source: GitHub Actions).
